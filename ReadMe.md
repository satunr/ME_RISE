**Specific.py**
<p align="justify"> This short script demonstrates how the spread dynamics vary in the same network when different seed sets are chosen. It generates a small directed Erdős–Rényi graph with 15 nodes and edge probability 0.1. For two iterations, it selects two seed nodes using degree-weighted sampling and computes node-level spread via the spread_reach function over T = 20 time steps with an activation probability of 0.2. Each node’s spread is stored as a node attribute (weight), with seeds fixed at 1.0, and the resulting node-weighted network is saved to separate GML files (Save0.gml, Save1.gml). This setup allows comparison of how different seeds influence reachability and diffusion patterns in the same underlying network. </p>

**Main1.py**
<p align="justify"> This script implements a simulation framework for evaluating how adding new edges affects information spread in directed networks such as Gnutella or Wiki-Vote. It constructs K-hop ego networks around seed nodes and uses adjacency matrix powers to estimate multi-step reachability between nodes. Each potential edge (u, v) is scored based on how much it improves reach from seeds to reachable nodes within the ego network, forming the ME-RISE score. The top-scoring edge is added to the graph, and its impact on spread is compared against random baselines across multiple iterations. A one-sample t-test is then applied to determine whether the improvement frequency exceeds random chance, enabling a statistical evaluation of edge importance across repeated runs. </p>

**Main2.py**
<p align="justify"> This script extends the simulation framework described in Main1.py to evaluate incremental influence maximization through iterative edge addition in directed networks. It repeatedly generates weighted random subnetworks, sparsifies them, and selects seed nodes based on out-degree centrality to initiate the diffusion process. At each iteration, the algorithm constructs a K-hop ego network around the seed set and scores all potential new edges using the ME-RISE criterion, which measures marginal improvements in multi-step reachability. The top-scoring edge is added to both the global and ego graphs, and the resulting gain in spread is compared against a random rewiring baseline. The process continues for a fixed number of switches, maintaining statistics across multiple independent runs. The script visualizes and tracks the running mean and variance of spread improvements over iterations, thereby quantifying the robustness and efficiency of the proposed edge selection strategy relative to random exploration. </p>

**Main_Rewire.py**
<p align="justify"> This script extends the edge-augmentation framework from Main2.py by introducing an adaptive edge rewiring mechanism for influence maximization in directed networks. Instead of merely adding edges, the algorithm maintains a fixed edge count by simultaneously removing expendable links—those not part of the ego network around influential seeds—and adding new ones that maximize the marginal gain in diffusion spread. The function sort_expendables() identifies low-importance edges based on in-degree ordering, while the scoring routine reuses the ME-RISE criterion to evaluate potential additions within the ego subgraph. Each iteration selects the highest-scoring edge to add and removes one expendable edge, effectively rewiring the network while preserving sparsity. The method is compared against a random rewiring baseline across multiple Monte Carlo runs, tracking the cumulative improvement in reachability. Results show that targeted rewiring systematically enhances spread efficiency relative to random modifications while maintaining network compactness. </p>

**Main1_Scale1.py**
<p align="justify"> This script is a scaled/optimized variant of the ME-RISE scoring pipeline (see Main1), focused on operating only on the ego subgraph for efficiency. For each iteration, it samples a weighted subgraph, builds a K-hop ego network around degree-weighted seed nodes, and then trims and reorders the graph via arrange so that the adjacency submatrix corresponding to the ego network can be used directly. The algorithm computes powers of this reduced adjacency matrix to get multi-step reachability, evaluates first-order seed→node connectivity and second-order marginal gains for every candidate missing edge, and normalizes those values into edge scores. The top-scoring edge is added, and spread is estimated using spread_reach; the chosen edge’s spread is compared to the average spread of random candidate edges to register a hit or miss. The script records per-iteration runtimes, accuracy counts, and timing statistics, making it suitable for experiments that measure how the scoring method scales when applied to larger real-world subnetworks while maintaining the same evaluation logic as Main1. </p>

**Viz_Scale.py**
This script visualizes runtime comparisons between two groups (e.g., “Unscaled” vs. “Scaled”) across different network sizes. It uses Matplotlib to create a grouped bar chart with error bars, plotting example data for subnetworks and full networks. The y-axis is set to a log scale to accommodate large runtime differences. The chart clearly shows how scaling affects performance, with distinct coloring for each group and labeled axes. This approach can be adapted for any network dataset by replacing Y1, Y2, and their corresponding errors.
